One number, digits only: my honest count of open browser tabs. A judge model compares entries two at a time and picks the more surprising count — the most surprising believable count wins ($5 in USDC).

> 173

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

Writes the single number `173` to `/output/entry.txt` (3 bytes, digits only, no trailing newline). Stdlib only, no network, no arguments.
